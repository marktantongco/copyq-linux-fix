CopyQ on Ubuntu 26.04 Wayland

Ubuntu 26.04 LTS is the first Wayland-only LTS release — no Xorg session available. CopyQ 16.0.0 from Flathub brings clipboard management back, bridging X11 and native Wayland apps seamlessly.

The Problem

Three blockers prevent CopyQ from working out of the box

GNOME 50 on Ubuntu 26.04 LTS introduces breaking changes that stop clipboard managers relying on X11 or the wl-data-control protocol.

GNOME 50 is Wayland-Only

Ubuntu 26.04 LTS is the first Wayland-only LTS — no Xorg session available. Every application must function under the Wayland compositor.

No wl-data-control Protocol

GNOME 50 mutter does not implement the wl-data-control protocol, so clipboard managers cannot intercept or manage clipboard contents natively.

PPA Stuck at v13

The official CopyQ PPA has not been updated past version 13.0.0. The latest release, CopyQ 16.0.0, is only available from Flathub.

Architecture

The Solution

Three components that make it work

This project combines XWayland bridge configuration, Flatpak v16 packaging, and GNOME keyboard shortcuts into a single automated installer.

XWayland Bridge

Configures CopyQ to use X11 clipboard through XWayland. The compositor bridges X11 selections to native Wayland clipboard, enabling cross-protocol sync.

Clipboard Bridge

Flatpak v16

Installs CopyQ 16.0.0 from Flathub (PPA stuck at 13.0.0) with proper Flatpak permissions and portal access for Wayland and X11.

Flathub Package

GNOME Shortcuts

Configures global keyboard shortcuts via GNOME settings so you can toggle CopyQ, show the clipboard history, and paste items from anywhere.

Keyboard Shortcuts
Install

Get up and running in one command

Clone the repo, make the scripts executable, and run the installer. It handles system checks, Flatpak setup, environment configuration, and shortcut setup.

Install

Step 1

Clone the repository and run the unified installer. It checks your system, installs CopyQ 16.0.0 from Flathub, configures XWayland bridge, and sets up keyboard shortcuts.

Terminal
git clone https://github.com/marktantongco/copyq-linux-fix.git && \ cd copyq-linux-fix && \ chmod +x install.sh scripts/*.sh && \ ./install.sh

Uninstall

Step 2

Remove all configuration, shortcuts, and Flatpak overrides. The Flatpak package itself is not removed — use your package manager if needed.

Terminal
./install.sh --uninstall
